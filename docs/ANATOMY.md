# Anatomy: names for everything

Every part of the site has one stable name. Use these names in issues, PRs and chat
("make the `site-sidebar` collapse on tablets", "add a `cell-warn` colour").

## Page regions (site/template.html)

```
┌──────────────────────────────────────────────────────────────┐
│ site-header   [menu-button] [brand]              [site-search]│
├────────────┬─────────────────────────────────────────────────┤
│            │ page                                            │
│ site-      │   page__title        (the <h1>)                 │
│ sidebar    │   page__body         (content/*.html goes here) │
│            │   page__footer                                  │
│            │     page__categories · page__credits            │
├────────────┴─────────────────────────────────────────────────┤
│ site-footer   licence · disclaimer · links                   │
└──────────────────────────────────────────────────────────────┘
```

| Name | What it is | Where |
|---|---|---|
| `site-header` | Sticky top bar | `site/template.html` |
| `site-header__brand` | Logo + tagline link to the home page | template |
| `site-header__menu-button` | ☰ button, mobile only | template + `site.js` |
| `site-search` | Search box + dropdown (`site-search__input`, `site-search__results`, `search-result`) | template + `search.js` |
| `site-sidebar` | Left navigation | `content/_nav.html` |
| `nav-group` | One titled block of sidebar links (`nav-group__title`, `nav-group__list`) | `_nav.html` |
| `page` | Main column | template |
| `page__title` | The page's `<h1>`, filled from the `title:` metadata | template |
| `page__body` | The article. **This is where a content file's HTML lands.** | `content/*.html` |
| `page__footer` | Categories and contributor credits | generated by `build.py` |
| `category-tag` | A category pill | generated |
| `site-footer` | Licence, disclaimer, links | template |

## Content vocabulary (use these inside `content/*.html`)

**Tables**

| Class | Use |
|---|---|
| `wiki-table` | Every data table (the converter adds it) |
| `wiki-table--wide` | Stretch to full width |
| `wiki-table--center` | Centre all cells |
| `table-scroll` | Wrapper div that lets wide tables scroll sideways on phones |
| `cell-yes` / `cell-no` | Bold green "Yes" / red "No" cells |
| `cell-good` / `cell-bad` | Soft green / red background (bonuses / penalties) |
| `cell-head` | Blue heading-style cell |
| `cell-band` | Grey banding |
| `cell-dark` | Black cell with white text |
| `cell-center` | Centre the text |

**Dates on numbers.** Every data table gets a `data-note` line under it: "Numbers last updated 13 Feb 2026".

- The date comes from the page's header: `updated: 2026-02-13` (also accepts `2026-02` or `2026`).
  **Whoever changes numbers on a page bumps `updated:`.**
- If only one table on a page changed, give that table its own date:
  `<div class="table-scroll" data-updated="2026-05-01">`.
- Layout tables that hold no numbers opt out with `data-updated="none"` (the converter does this automatically).
- Formulas or numbers in plain text (not in a table): add `<p class="data-note">Numbers last updated 1 Jan 2026.</p>` yourself.
- `python3 build.py` warns about any data table that has no date.

**Boxes and lists**

| Class | Use |
|---|---|
| `infobox` | Floating side box (right-aligned on desktop, full width on mobile) |
| `callout` | Highlighted note in the flow of text |
| `page-list` | Multi-column list of links |
| `<details><summary>` | Collapsible section (no JavaScript) |

**Links between pages** are plain relative links to the flat file name:
`<a href="magic-formulas.html">Magic Formulas</a>` or with an anchor: `href="mystics.html#Animate_Dead"`.
`python3 build.py --check` fails if any link points nowhere.

## Colours and fonts

All colours are variables at the top of `site/assets/style.css` (`--bg`, `--accent`, `--yes-bg`, …)
with a dark-mode set under `prefers-color-scheme: dark`. Change a variable, not individual rules.
