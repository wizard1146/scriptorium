What is Seraphiel?

Seraphiel is basically a set of user-interface improvements for the online game Utopia. It is a Mozilla Firefox add-on.

Developer Jivlain [open source]

Download Link http://users.on.net/~jivlain/seraphiel.0.84.xpi

Requirements

  • Mozilla Firefox

Features

Features (integrated into the Main Utopia Page)
Remember T/M settings
Remember recent T/M ops
Sortable kingdom pages
Buildings calculator
Themes (choose your own colour scheme for Utopia)
Monarch message shown on each page
All locations converted into links
Kingdom tags
Links to common council pages in the top bar.
Intra-kingdom mass messaging assist
Multi-tap assist
Military cost calculator
Shows raw offense as you prepare your armies
Highlights low food situations
Direct links to the magic, thievery, and send messages pages from the kingdom page.
Links to the kingdom page from the magic, thievery, send messages and war room page.
Throne page/Science page/Buildings page/SoT/Survey/SoS/SoM formatters
