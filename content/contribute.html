Scriptorium is a community wiki that lives entirely in a GitHub repository. There is no login, database or server: every page is a small HTML file, and every improvement is a pull request.

Fix a typo or update a number

  1. Open the page's file in the content folder (the file name matches the page's address, so magic-formulas.html is content/magic-formulas.html).
  2. Click the pencil icon, make your change, and choose Propose changes.
  3. GitHub opens a pull request. The build checks your links automatically, and a maintainer merges it. The live site updates within a minute or two.
Changing a formula or a value? Say which Age it applies to, link your source in the pull request description, and update the updated: date in the comment at the top of the file. That date appears under every table as “Numbers last updated…”.

Add a page

Create content/my-page.html. Start it with a comment holding the title and categories, then plain HTML:

<!--
title: My Page
category: Guides
updated: 2026-09-25
-->
<p>Text goes here. Link to another page like <a href="units.html">this</a>.</p>

Then link to it from a related page or from content/_nav.html so people can find it.

Making things look right

Don't use inline style=. The site has named classes for tables, colours and boxes, all listed in docs/ANATOMY.md.

Ground rules

  • Content is CC BY-NC 3.0 US. No advertising or commercial links, and nothing you can't license that way.
  • Do not publish information about cheating or exploits.
  • Be accurate and cite the Age a fact applies to; Utopia changes every Age.
